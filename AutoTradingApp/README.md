# Auto Trading App (안드로이드 클라이언트 앱)

본 프로젝트는 주식 및 가상화폐(코인) 자동매매를 모니터링하고 제어하기 위한 안드로이드 네이티브 애플리케이션입니다.
Firebase Realtime Database를 통해 Python 기반의 백엔드 트레이딩 엔진과 실시간(0.1초 이내)으로 연동됩니다.

## 🚀 주요 기능

- ⚡ **'⚡ 퀀트스윙' 대시보드:**
  - 미국 필라델피아 반도체 3배 레버리지(`SOXL`) / 인버스 3배(`SOXS`) 퀀트 스윙 전략 전용 화면
  - 전일 `SOXX 200MA` 거시 국면 배지 및 `SOXX RSI(14)` 실시간 진입 필터 현황
  - 진입 종목 실시간 평가손익, 익절 목표가(TP), 트레일링 스탑 라인, -5% 손절선 안내
  - 당일 4단계 분할 매수 현황 및 실시간 체결 로그
  - 비상 시장가 전량 청산(Emergency Exit) 버튼
- 👥 **원클릭 다중 가족 프로필 관리 및 기기별 PIN 보안:**
  - 상단 앱바 칩 터치 한 번으로 본인 및 가족(자녀 등) 계좌로 0.1초 만에 전체 화면 데이터(잔고/설정) 즉시 전환
  - 프로필 스위치 시 메모리 상태 즉시 초기화(`resetUserData`)로 계정 간 데이터 혼선 차단
  - 4자리 PIN 설정 시 미인증 기기 열람 차단 및 로컬 기기 기억하기(자동 해제) 지원
  - 프로필 이름 수정(✏️) 및 고유 ID 자동 생성 지원
- 🏛️ **멀티 브로커 계좌 설정:**
  - 한국투자증권(국내/해외/모의), 메리츠증권(실전 국내/해외), 키움증권(실전/모의), 업비트 연동 지원
  - 상단 톱니바퀴(`⚙️`) 버튼을 통해 원클릭 계좌 정보 등록 및 변경
- 📊 **실시간 자산 및 보유 종목 대시보드:**
  - 총 평가자산(평가액 + 현금 예수금), 계좌 수익률, 주문가능 예수금 실시간 조회
  - 보유 종목별 매수평균가, 현재가, 평가손익률, 실시간 시세 변동률 확인
- 📈 **수동 주문 및 조건부/손절매 주문:**
  - 시장가/지정가 수동 매수·매도 주문 발주
  - 목표가 도달 시 자동 매도(조건부 주문) 및 하락 시 원금 보호(자동 손절매 주문)
- 🤖 **급등주 감시 및 자동매매 설정 (🚀):**
  - 종목별 시간(초), 급등 퍼센트(%), 매수 수량 조건 다중 설정 및 실시간 ON/OFF
- 🌅 **장전시간외 매수 주문예약 관리:**
  - 08:20 정각 대기열 선점 예약 및 미국장 연동 08:00 자동 취소 설정 지원
- ♾️ **라오어 무한매수 대시보드:**
  - 실계좌 매수평단가 vs 시장 현재가 직관적 비교, 진행 회차 및 목표수익률 시각화

## 🛠 기술 스택

- **언어:** Kotlin
- **UI 프레임워크:** Jetpack Compose (Material3)
- **아키텍처:** MVVM / MVI (ViewModel, StateFlow)
- **백엔드 연동:** Firebase Realtime Database
- **푸시 알림:** Firebase Cloud Messaging (FCM)
- **비동기 처리:** Kotlin Coroutines

## ⚙️ 설치 및 빌드 방법

1. **저장소 클론:**
   ```bash
   git clone <repository-url>
   ```
2. **Firebase 연동:**
   - Firebase Console에서 안드로이드 프로젝트를 생성합니다.
   - `google-services.json` 파일을 다운로드하여 `app/` 디렉터리 내에 배치합니다. (보안상 GitHub에는 `google-services_template.json`만 제공됩니다.)
3. **빌드:**
   - Android Studio에서 프로젝트를 엽니다.
   - 터미널에서 아래 명령어로 빌드합니다:
   ```bash
   ./gradlew assembleDebug
   ```

## ⚠️ 보안 주의 사항
- `app/google-services.json` 파일은 Firebase 접속 정보를 담고 있으므로 절대 공개 저장소에 커밋하지 마세요. (본 저장소의 `.gitignore`에 추가되어 있습니다.)
