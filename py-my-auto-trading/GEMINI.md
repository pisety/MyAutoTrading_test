# Backend Auto-Deployment Rule

**이 프로젝트의 백엔드 파이썬 코드(엔진, 브로커, DB 로직 등 .py 파일)를 수정한 후에는, 반드시 작업의 마지막에 `server.bat deploy` 명령어를 실행하여 오라클 클라우드에 수정 사항을 자동 배포해야 합니다.**

- **실행 명령어**: `.\server.bat deploy`
- **조건**: `.py` 파일 내용이 변경되어 실제 서비스 로직이 수정된 경우 항상 수행
- **예외 사항**: 사용자가 명시적으로 배포하지 말라고 지시한 경우를 제외하고는 항상 이 규칙을 따릅니다.
